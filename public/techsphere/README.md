# TechSphere University — Static Website

Premium, responsive static website for TechSphere University. Built with pure HTML5, CSS3 and vanilla JavaScript — no build step, no backend.

## Pages
- `index.html` — Home (hero, skills, training info, why-choose, CTA)
- `about.html` — Mission, Vision, offerings, stats
- `portal.html` — Glassmorphism student login (frontend demo)
- `support.html` — Contact cards, form, FAQ, map placeholder

## Features
- Fully responsive (mobile / tablet / desktop)
- Sticky navigation with mobile menu
- Dark mode toggle (persisted in localStorage)
- Smooth scrolling, fade-in reveals, animated counters, ripple buttons, floating hero art
- Scroll-to-top button, loading animation
- SEO meta tags, semantic HTML, WCAG-friendly

## Deploy to Hostinger
1. Download the entire `techsphere/` folder.
2. Upload contents to your Hostinger `public_html/` via File Manager or FTP.
3. Done — visit your domain.

## Tech
- Fonts: Poppins + Inter (Google Fonts)
- Color palette: Blue `#0b3a8f`, White `#ffffff`, Red `#e11d2a`
- No dependencies, no frameworks.
